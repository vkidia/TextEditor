# Текстовый Редактор — Инструкция по запуску в VS Code

## Структура проекта

```
TextEditor/
├── main.py          ← ЗАПУСКАТЬ ЭТОТ ФАЙЛ
├── editor.py        ← главное окно и весь UI
├── file_manager.py  ← открытие, сохранение, экспорт файлов
├── dialogs.py       ← диалоговые окна (таблица, список, ссылка, график)
└── config.py        ← цвета, иконки, константы
```

---

## Шаг 1 — Установить Python

1. Перейти на **https://www.python.org/downloads/**
2. Скачать Python 3.10 или новее
3. При установке поставить галочку **"Add Python to PATH"** ✓
4. Проверить: открыть `cmd` и ввести `python --version`

---

## Шаг 2 — Установить VS Code

1. Скачать с **https://code.visualstudio.com/**
2. Установить с настройками по умолчанию

---

## Шаг 3 — Установить расширение Python в VS Code

1. Открыть VS Code
2. Нажать `Ctrl+Shift+X` (Extensions)
3. В поиске ввести **Python**
4. Установить расширение от **Microsoft** (первое в списке)
5. Перезапустить VS Code

---

## Шаг 4 — Открыть проект

1. В VS Code: **File → Open Folder** (`Ctrl+K, Ctrl+O`)
2. Выбрать папку **TextEditor** (ту, где лежат все .py файлы)
3. VS Code покажет все файлы в боковой панели слева

---

## Шаг 5 — Установить зависимости

Открыть терминал прямо в VS Code: **Terminal → New Terminal** (`Ctrl+\``)

Выполнить в терминале:

```bash
pip install Pillow reportlab
```

> Если не работает — попробуйте:
> ```bash
> python -m pip install Pillow reportlab
> ```

**Что устанавливается:**
- `Pillow` — для вставки изображений (PNG, JPG и др.)
- `reportlab` — для экспорта документов в PDF

---

## Шаг 6 — Запустить программу

### Способ A (самый простой):
1. Открыть файл **`main.py`** в редакторе (кликнуть на него слева)
2. Нажать **`F5`** — запуск с отладчиком
   - При первом запуске VS Code спросит конфигурацию — выбрать **Python File**

### Способ B (без отладчика):
1. Открыть **`main.py`**
2. Нажать **`Ctrl+F5`** — запуск без отладчика (быстрее)

### Способ C (через терминал):
```bash
python main.py
```

---

## Если что-то не работает

**Ошибка "No module named 'tkinter'"** (редко, на Linux):
```bash
sudo apt install python3-tk
```

**Ошибка "No module named 'PIL'"**:
```bash
pip install Pillow
```

**Ошибка "No module named 'reportlab'"**:
```bash
pip install reportlab
```

**VS Code не видит Python:**
1. `Ctrl+Shift+P` → написать `Python: Select Interpreter`
2. Выбрать нужную версию Python из списка

**Окно не появляется (Windows):**
Убедитесь что запускаете `main.py`, а не другой файл.

## Горячие клавиши

| Клавиши | Действие |
|---------|---------|
| `Ctrl+N` | Новый файл |
| `Ctrl+O` | Открыть |
| `Ctrl+S` | Сохранить |
| `Ctrl+Shift+S` | Сохранить как |
| `Ctrl+Z / Y` | Отменить / Повторить |
| `Ctrl+X / C / V` | Вырезать / Копировать / Вставить |
| `Ctrl+A` | Выделить всё |
| `Ctrl+F` | Найти и заменить |
| `Ctrl+B` | Жирный |
| `Ctrl+I` | Курсив |
| `Ctrl+U` | Подчёркнутый |
| `Ctrl+L / E / R / J` | Выравнивание |

## Форматы сохранения

| Формат | Как сохранить |
|--------|--------------|
| `.txt` | Файл → Сохранить |
| `.rtf` | Файл → Сохранить как → выбрать RTF |
| `.pdf` | Файл → Экспорт в PDF |
